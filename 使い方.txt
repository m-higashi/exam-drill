過去問練習アプリ（exam-drill） ── はじめての方向けの使い方
============================================================

自分で用意した問題を、演習・復習つきの練習アプリにする道具です。
問題を書く画面も入っているので、ファイルを手で編集する必要はありません。

  ※ このアプリに問題は入っていません（サンプルが数問だけ）。
     あなたの問題に差し替えて使ってください。


────────────────────────────────────────────
■ 1. 用意するもの
────────────────────────────────────────────

  ・Python 3.9 以降
      入っているかの確認：
        Windows … コマンドプロンプトで  python --version
        Mac     … ターミナルで          python3 --version
      入っていなければ https://www.python.org/downloads/ から。
      （追加のインストールは要りません。標準の機能だけで動きます）

  ・ブラウザ（Chrome / Edge / Safari / Firefox）


────────────────────────────────────────────
■ 2. 起動する
────────────────────────────────────────────

  Windows … フォルダの中の「start.bat」をダブルクリック
  Mac/Linux … 「start.command」をダブルクリック

  黒い画面が出て、次のようにアドレスが表示されます。

        ▶ アプリURL:  http://127.0.0.1:8787/

  ★ 画面に出たアドレスを、そのままブラウザで開いてください。
    （Tailscale が入っていると http://100.○.○.○:8787/ のような
      別のアドレスになります。その場合 127.0.0.1 では開けません）

  ※ 黒い画面は開いたままにしてください（閉じると止まります）。


  ── Mac で困ったときは ──

  ・「開発元を確認できないため開けません」と出る
      インターネットからダウンロードしたときに出ます。
      macOS 15 以降は「右クリック → 開く」が効きません。
        システム設定 → プライバシーとセキュリティ → 下の方の「セキュリティ」欄
        →「"start.command" は開発元を確認できないため…」の右の【このまま開く】
      ※ 画面には何も出ず、通知だけのことがあります。押しても何も起きないように
        見えたら、上の設定画面を見てください。

  ・「permission denied」と出る
      ターミナルで、このフォルダに移動して次を一度だけ実行してください。
        chmod +x start.command

  ・「Operation not permitted」と出る
      macOS の保護が掛かるフォルダ（ダウンロード・デスクトップ・書類）に
      置くと、ターミナルから触れないことがあります。
      ホームフォルダの直下など、保護の掛からない場所に移してください。

  ・python3 が見つからない
      macOS には Python が入っていないことがあります。
      https://www.python.org/downloads/ から入れてください（3.9 以降）。


────────────────────────────────────────────
■ 3. 使ってみる
────────────────────────────────────────────

  メニューから選べます。

    年度別演習 …… 年（またはセット）を選んで順に解く。途中でやめても続きから
    シャッフル演習 … 全問をシャッフルして出題
    復習演習 …… まちがえた問題と★を付けた問題だけを解く
    参照 ……… 採点せずに、全問の解答と解説を読む
    編集 ……… 問題と解説を書く（次の項）

  ・選択肢が1つだけの問題は、選んだ瞬間に採点されます。
  ・「2つ選べ」の問題は、選んでから「解答する」を押します。
  ・各問題の右上の ★ で、あとで見直す印を付けられます。
  ・学習記録は開いた端末のブラウザに保存されます（端末ごとに別々）。


────────────────────────────────────────────
■ 4. 自分の問題を入れる
────────────────────────────────────────────

  ★ 答えが分からなくても、先に入れてしまってかまいません。
     過去問には解答が付いていないのがふつうです。このアプリは
     「問題だけ先に入れて、解きながら答えと解説を足していく」使い方を
     想定しています。

  【まとまった数があるとき：メモ帳で書いて取り込む】

    1. メモ帳で、次のように書いて保存します（文字コードはそのままでOK）。

         2024

         問1
         問題文をここに書きます。
         a 選択肢その1
         b 選択肢その2
         c 選択肢その3

         問2
         答えが分かっているものは、こう書きます。
         a 選択肢その1
         b 選択肢その2
         答え: b
         解説:
         【総論】ここに解説を書きます。
         a …×　違う理由。
         b …○（正解）

       ※「答え:」の行は書かなくてかまいません。
         書かなかった問題は採点されず、「解説を見る」だけになります。

    2. メニューの「✎ 問題と解説を編集」→「📄 テキストから取り込む…」
    3. 「ファイルを選択」で保存したファイルを選ぶ（貼り付けてもOK）
    4. 「読み取って確認する」を押す
         → 何問読み取れたか、どこがおかしいかが出ます。
           **この時点ではまだ何も書き換わりません。**
    5. よければ「追加する」

    ・書き方の見本は「書き方の見本を入れる」ボタンで読み込めます。
      同梱の data/sample.txt がそれです。
    ・決まりの一覧は同じフォルダの「データ形式.md」にあります。
    ・うまく読めないときは、確認の画面が「何行目で何が起きたか」を教えます。
      多いのは次の3つです。
        ・先頭に「2024」のような数字だけの行が無い
        ・問題文を、選択肢より後に書いている
        ・「画像」「出典」に「:」を付けていない

  【★ 問題集の名前を変える】

    自分の問題を入れたら、名前が「サンプル問題集」のままになります。
    「✎ 問題と解説を編集」→「この問題集の名前」で変えられます。
      ・正式名   … 画面の下部に出ます
      ・短い名前 … 画面の左上に出ます
      ・出典の説明 … 下部に出ます（空でもかまいません）

  【★ 画像を1枚ずつ入れるとき（いちばん簡単）】

    編集画面の「画像」欄のすぐ下に、受け取り欄があります。

    1. 画像のファイルを、その欄にドラッグ＆ドロップします
       （欄を押してファイルを選んでも同じです。何枚でもまとめて置けます）
    2. data\images\<年>\ に入り、上の「画像」欄に場所が足されます
    3. ★そのままでは、まだこの問題の画像になっていません。
       「保存」を押してください

    ・入れられる形は png / jpg / jpeg / gif / webp。1枚 12MB まで
    ・同じ名前があっても上書きしません（図-2.png のように番号が付きます）
    ・画像でないファイルは入りません（理由が画面に出ます）

  【★ 画像をまとめて入れるとき（おすすめ：フォルダから自動で割り当てる）】

    PDFから切り出した画像は「001-image01.png」のように、
    先頭に問題番号が入っていることがほとんどです。それをそのまま使えます。

    1. data\images\ の中に、年ごとのフォルダを作って画像を入れます
         data\images\2024\001-image01.png
         data\images\2024\001-image02.png
         data\images\2024\002-image01.png
    2. メニューの「✎ 問題と解説を編集」→「📁 画像を割り当てる…」を押します
    3. 「2024年 75問に161枚」のような計画が出るので、確かめて「割り当てる」

    ・ファイル名の【先頭の数字】を問題番号として紐づけます
        001-image01.png → 問1 ／ 12.jpg → 問12 ／ fig-3.png → 問3
    ・すでに画像が入っている問題は触りません
      （入れ直したいときは「すべて置き換える」を選びます）
    ・番号に合う問題が無いファイルは飛ばし、その一覧を出します
    ・テキストに「画像:」の行を書く必要はありません

  【1枚ずつ手で指定するとき】

    テキストの中に、その場所を書きます。

         画像: data/images/2024/q01.png

    ・区切りは「/」で書きます（「\」でも通ります）
    ・1問に何枚でも書けます。行を分けてください
    ・パスを手で並べるのが大変なときは、フォルダの中で
      「Shift+右クリック → パスのコピー」を使うと楽です

  【1問ずつ書くとき】

    1. メニューの「✎ 問題と解説を編集」を開く
    2. 「問題を追加する」に年（例 2025）を入れて「追加して編集する」
    3. 問題文・選択肢・解答・解説を書いて「保存」

  【サンプルを消して、まっさらから始めたいとき】

    取り込みの画面で「すべて置き換える…」を使うと、いまの問題を全部捨てて
    読み取った内容だけにできます（控えは残ります）。

    または data/sample.json をメモ帳で開き、中身を次の2文字だけにして保存します。

        []

  ※ 書き換える前の控えが data/_backup/ に自動で残ります（直近10世代）。
     間違えて消してしまったときは、そこから戻せます。


────────────────────────────────────────────
■ 5. 覚えておくとよいこと
────────────────────────────────────────────

  ・入力した内容は「保存」を押すまで「書きかけ」として端末に残ります。
    画面の上に「書きかけ ○件（未保存）」と出ます。
    どこか1か所で「保存」を押せば、他の問題の書きかけも一緒に保存されます。

  ・「書式を検査」を押すと、解説の形（各選択肢に○×が付いているか等）を
    助言します。揃っていなくても保存はできます。

  ・編集トップに「未作成の解答 ○問」「未作成の解説 ○問」「要確認 ○問」が出ます。
    押すと、その問題だけを順に開けます。残りが一目で分かります。

  ・答えが定まっていない問題は「要確認」を付けておけます。
    解答を空にすると、採点せず解説だけを見せる問題になります。

  ・保存していない編集があると、画面の右上に
    「✎ 書きかけ ○件（未保存）」と出ます。どの画面にいても見えます。
    押すと編集画面に移り、まとめて保存できます。

  ・書いたものを取りやめたいときは「保存せずに捨てる…」を押します。
    先に「何を捨てるか」が出るので、確かめてから「捨てる」。
    捨てた直後なら「元に戻す」で戻せます（画面を移ると戻せなくなります）。
    ★捨てられるのは、その画面で書いた分だけです。保存済みの内容は消えません。

  ・編集はサーバーを動かしているパソコンからだけできます。
    他の端末のブラウザには編集の入口が出ません。


────────────────────────────────────────────
■ 6. スマホ・タブレットから使う
────────────────────────────────────────────

  Tailscale（https://tailscale.com/ ・個人利用の無料枠があります）を
  パソコンとスマホの両方に入れてください。自分の端末どうしだけをつなぐ
  VPNで、社内LANやインターネットには公開されません。

  入れたあと起動すると、http://100.x.y.z:8787/ の形のアドレスが表示
  されるので、スマホのブラウザでそれを開きます。

  ・Windows では初回だけ、ファイアウォールでポートの許可が要ります。

  ⚠️ このアプリにパスワードはありません。
     server_config.txt の ip= を空欄のまま Tailscale も使っていない場合、
     同じネットワークの人から中身が見えます。人に見せたくない問題を
     入れるときは、ip=127.0.0.1 にしてこのパソコン専用にしてください。


────────────────────────────────────────────
■ 7. 待受け先・ポートを変える
────────────────────────────────────────────

  server_config.txt を書き換えて保存し、起動し直します。

        ip=127.0.0.1     ← このパソコンだけで使う（いちばん安全）
        ip=              ← 空欄なら Tailscale の IP を自動で探す
        port=8787        ← ポート番号

  ※ メモ帳で保存するときは、文字コードを「UTF-8」にしてください
    （「UTF-8 (BOM付き)」でも読めるようにしてあります）。


────────────────────────────────────────────
■ 8. 人に配るとき
────────────────────────────────────────────

  ・読み取り専用にしたい（編集させたくない）場合は、
    authoring.py を削除してください。編集の入口ごと出なくなります。

  ・問題の権利にご注意ください。他人が作った問題をそのまま配ることは
    できないことがあります。
