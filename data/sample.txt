問1
このアプリで、1問ぶんのデータに必ず要るものはどれか。
a year（年・セットの番号）
b no（問題番号）
c stem（問題文）
d images（画像）
e sources（出典）
答え: c
解説:
【総論】1問に必ず要るのは year・no・stem・choices の4つ。images と sources は無くてもよい。
a year …△（要るが、この設問は「問題文そのもの」を問うている）
b no …△（同上）
c stem …○（正解）　問題文。これが無いと問題として成立しない。
d images …×　画像は任意。無ければ書かなくてよい。
e sources …×　出典は任意。
※これはサンプル問題です。あなたの問題集に差し替えてお使いください。

問2
複数選択の問題である。正しいものを2つ選べ。
a answer に2つ以上入れると「2つ選べ」の形式になる
b 選んだ順番も採点される
c 選び終えてから「解答する」を押して採点する
d 1つでも当たっていれば正解になる
e 複数選択は使えない
答え: a, c
解説:
【総論】answer に複数の記号を入れると複数選択になる。選んだ集合が正解と完全に一致したときだけ正解。
a …○（正解）
b …×　順番は見ない。集合として比べる。
c …○（正解）　単一選択はタップで即採点、複数選択は「解答する」を押す。
d …×　部分点は付かない。
e …×

問3
図は、このアプリの画面の並びを示したものである。図に関する記述として正しいのはどれか。
画像: data/images/sample-figure.png
a 画像はインターネット上のURLを書く
b 画像はこのフォルダの中に置き、相対パスで書く
c 画像は1問に1枚までである
d 画像は必ず必要である
e 画像はタップしても拡大できない
答え: b
解説:
【総論】画像はアプリのフォルダの中に置き、`data/images/…` のような相対パスで指定する。外部URLは受け付けない（手元だけで完結させるため）。
【図の見かた】メニュー →（演習／参照／編集）の3つに分かれることを示している。
a …×　外部URLは指定できない。
b …○（正解）
c …×　何枚でも並べられる。
d …×　無くてよい。
e …×　タップで拡大表示できる。

問1
「要確認」を付けた問題の扱いとして正しいのはどれか。
a 演習に出てこなくなる
b 画面に印が出るが、採点はふつうに行われる
c 自動的に削除される
d 解説が非表示になる
e 他の問題より先に出題される
答え: b
要確認
出典: 同梱の データ形式.md 「flag」の項
解説:
【総論】flag を true にすると「要確認」の印が付く。答えが割れている・情報が古いかもしれない問題に付けておく。
a …×　ふつうに出題される。
b …○（正解）
c …×
d …×
e …×　ただし編集モードには「要確認だけを順に見る」がある。
【結論】b。要確認はあくまで印であって、出題や採点の動きは変えない。
※この問題自体に「要確認」を付けて、印の見え方の見本にしています。

問2
答えをまだ書いていない問題は、どう扱われるか。
a エラーになる
b 採点せず、解説だけを見せる問題になる
c すべての選択肢が正解になる
d 表示されない
答え:
要確認
出典: 同梱の データ形式.md 「answer」の項
解説:
【総論】答えを書いていない問題は採点の対象外になり、「解説を見る」だけができる。**手元に解答が無い過去問を、先に全部入れてしまう**ための逃げ道。
a …×
b …○（正解）
c …×
d …×
【結論】b。編集画面の「未作成の解答 ○問」から、分かったものだけ順に埋めていける。
※この問題自体の答えを空にしてあるので、採点されない動きをそのまま確かめられます。

問3
答えの分からない問題を、先にまとめて入れておきたい。どうするのがよいか。
a 答えが分かるまで入力しない
b 「答え:」の行を書かずに入れておき、あとから編集画面で埋める
c 適当な答えを入れておく
d 別のファイルに分けておく
答え: b
出典: 同梱の 使い方.txt 「4. 自分の問題を入れる」
解説:
【総論】問題文と選択肢だけ先に入れてしまってよい。「答え:」の行は省略できる（この問題の1つ前がその例）。
a …×　入れておかないと、演習で解くこともできない。
b …○（正解）　編集トップの「未作成の解答 ○問」を押すと、その問題だけを順に開ける。
c …×　あとで正解と区別が付かなくなる。「要確認」を付けるほうがよい。
d …×　分ける必要はない。
